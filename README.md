# Roadmap Generator（路线图生成器）

基于 [Slint](https://slint.rs/)（Rust）开发的桌面应用，用于规划项目路线图：每个项目占一行，里程碑（milestone）绘制在共享时间轴上。

## 功能

- **添加里程碑**：输入项目名、里程碑名和日期即可添加；项目不存在时会自动创建（例如 `SPP`、`TR1=2026/08/20`、`TR4A=2026/09/25`）
- **新建项目**：通过 **New Project** 按钮创建空项目
- **时间轴展示**：每个项目一行，左侧为项目名，右侧为共享时间轴；里程碑按日期排序显示
- **选中与删除**：点击里程碑或项目行将其选中，然后通过 **Remove Selected Milestone / Project** 删除
- **颜色设置**：提供 9 种预设色（蓝/红/绿/橙/紫/青/灰/绯红/黑）并实时预览；选中里程碑时只改变该里程碑的颜色，仅选中项目时则改变该项目全部里程碑的颜色；颜色以 `#RRGGBB` 大写形式持久化
- **今日标记**：红色虚线 "We are here" 标出今天在时间轴上的位置（超出可视范围时自动隐藏），界面与导出图片中都会显示
- **导出图片**：导出为 **SVG** 或 **PNG**（使用 resvg 以 2 倍分辨率栅格化），通过系统文件对话框选择保存位置
- **文件操作**：**File** 菜单支持 **Open**（打开一个 `data.json` 替换当前数据）与 **Import (Merge)**（按项目名合并另一个 `data.json`，已存在的项目只补充缺失的里程碑）；**Save** 菜单或顶部 **保存** 立即保存数据，**Save As…（另存为）** 保存到指定位置并切换保存位置
- **自动持久化**：路线图数据默认保存到 `~/Documents/RoadMaps/data.json`（可在设置窗口自定义保存位置），程序设置（语言、主题、保存位置）保存到 `~/.RoadMapGenerator/config.json`；每次数据变更以及退出时自动保存，启动时自动加载恢复

## 构建与运行

```bash
cargo build
cargo run
```

## 使用说明

1. 输入项目名、里程碑名和日期（支持 `yyyy/mm/dd`、`yyyy-mm-dd`、`yyyy.mm.dd` 三种格式）
2. 点击 **Add Milestone** —— 项目及其里程碑出现在时间轴上
3. 点击 **New Project** 创建空项目
4. 点击时间轴上的里程碑（或左侧项目行）将其选中，然后点击 **Remove Selected Milestone / Project** 删除
5. 使用颜色下拉框选择预设色，为选中的里程碑或整个项目重新着色
6. 点击 **Export SVG** 或 **Export PNG** 通过文件对话框保存图片
7. 通过 **File** 菜单 **Open** / **Import (Merge)** 打开或合并其他 `data.json`，点击 **Save**（保存）立即保存数据，**Save As…**（另存为）保存到指定文件并切换保存位置
8. 打开 **Settings**（设置）可切换主题、语言，以及自定义数据保存位置（**Choose Folder…** 选择文件夹，**Reset to Default** 恢复为 `~/Documents/RoadMaps`）
9. 关闭窗口即自动保存数据，下次启动自动恢复

## 测试

```bash
cargo test
```
